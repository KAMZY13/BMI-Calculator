# 🧮 BMI Calculator — C++ Edition

A little C++ project with room to grow.

This started out as a school assignment, but I decided it deserved a little home on GitHub, too. So here it is: my first version of a **BMI Calculator built with C++**!

It's a simple console application for calculating Body Mass Index (BMI), but it has also been an opportunity for me to practise C++ fundamentals, learn from mistakes, and make a basic program a little more user-friendly.

## What can it do?

- Calculate BMI using weight in kilograms and height in metres.
- Display a BMI category based on standard adult BMI ranges.
- Validate inputs and flag values that appear invalid or suspicious.
- Help catch common mistakes, like entering height in centimetres instead of metres.
- Let users correct mistakes without restarting the program.
- Calculate multiple BMIs in one session.

## Built with

- **C++**
- GCC (MinGW-w64)
- VS Code

## How to run it

You'll need a C++ compiler installed on your computer.

1. Clone or download this repository.
2. Open the project folder in your terminal.
3. Compile the program:

   ```bash
   g++ BMI.cpp -o BMI
   ```

4. Run it on Windows:

   ```powershell
   .\BMI.exe
   ```

Follow the prompts, enter your measurements, and let the calculator do its thing
